# はじめに

Sekai は、Minecraft Java 版のリージョンファイル（`.mca`）を対象とした、チャンク単位で重複排除を行うバックアップ・復元ツールです。
スナップショットを迅速に記録し、任意の過去時点へワールドを素早く再構築できます。
長期保存用のアーカイブ用途ではなく、荒らし被害や更新失敗などのトラブル発生時に、稼働中のサーバーを直前の正常な状態へ素早く巻き戻す「ホットリカバリ」を高頻度に行う用途に最適化されています。

同一のチャンクデータはコンテンツアドレスストレージ (CAS) によって1つだけ保存され、複数のスナップショット間で共有されます。そのため、ワールドに変更がない場合のバックアップコストは、ワールド全体のコピーではなく、わずかメタデータ1行分の追加で済みます。
また、ロールバック実行時はスナップショット取得時の生バイトデータを寸分違わずアトミックに復元します。

Sekai は主に以下の2つを提供します：

- 本ガイドで解説する `sekai` CLI ツール
- サーバー管理ソフトウェア向けの再利用可能な Rust ライブラリ（`sekai-core` 上に構築された `sekai-app`）。ライブラリ API の仕様は rustdoc（`cargo doc`）を参照してください。本ガイドでは CLI の操作方法のみを取り扱います。

アーキテクチャの背景（レイヤ設計、2層ハッシュモデル、MVCC/GC データモデルなど）については [ARCHITECTURE.md](https://github.com/tmcjapan/sekai/blob/main/ARCHITECTURE.md) を参照してください。
機械可読な JSON 出力フォーマットの仕様は [docs/json.md](https://github.com/tmcjapan/sekai/blob/main/docs/json.md) に記載されています。
