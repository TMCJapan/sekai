# 自動化

すべてのコマンドは `--json` オプションに対応しています。標準出力 (stdout) には正確に1つの JSON ドキュメントが出力され、コマンド成功時には標準エラー出力 (stderr) に何も出力されず、ANSI エスケープシーケンス（カラーコード等）も一切含まれません。
また、`list` と `tag` を除くすべてのコマンドは `--timing` オプションに対応しており、通常テキスト出力時にはフェーズごとの処理時間テーブルを表示し、`--json` モードでは同一の計測データブロックを JSON ドキュメント内に含めて出力します。
進捗バーを標準エラー出力に描画する `--progress` は、機械処理用出力である `--json` との併用が拒否されます。

終了コード：
- `0`: 正常終了
- `1`: 実行時エラー（標準出力にエラー情報を含む JSON エンベロープが出力されます）
- `2`: コマンド使用法のエラー（引数パースエラーなど。clap が標準エラー出力にエラーメッセージを出力します）

各コマンドにおける dry-run（事前確認）の対応状況：

| コマンド / オプション | 事前確認（dry-run）の動作 |
|---|---|
| `status` | バックアップ全体の記録予定内容をプレビュー（設計上、`backup --dry-run` オプションは存在せず、本コマンドがその役割を担います） |
| `gc --dry-run`、`prune --dry-run` | 削除計画（plan）のみを表示し、実際のファイル削除は行わない |
| `rollback`、`export` | dry-run なし（rollback は定義上破壊的処理であり、export は空ディレクトリへの出力前提のため容易にやり直せるため） |

オプションの一覧、JSON エンベロープ形式、各コマンド固有のペイロード構造、下位互換性ポリシー（compatibility promise）などの完全な仕様については、[docs/json.md](https://github.com/tmcjapan/sekai/blob/main/docs/json.md) を参照してください。完全な仕様はそちらのリファレンスに定義されており、本ガイドでは重複する詳細説明を割愛しています。
