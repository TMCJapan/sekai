# サーバー連携

`sekai` はサーバープロセスを直接操作しません。バックアップ実行前後の書き込み停止・再開は、呼び出し側（自動化スクリプトや管理者）で行う必要があります：

1. `save-off`（サーバーによるリージョンファイルへの書き込みを一時停止）
2. `save-all`（メモリ上の未保存データをディスクへフラッシュ）
3. `sekai backup` を実行
4. `save-on`（書き込みを再開）

サーバーが並行して書き込みを行っている状態でワールドのバックアップを実行すると、書き込み途中の不整合なセクター（torn sector）が記録されてしまうおそれがあります。Sekai の読み取り処理は、バニラの Minecraft と同様に末尾の不完全なセクターを許容しますが、実際に破損しているセクタ列（run）を警告なしにバックアップすることはなく、エラーを報告して明確に失敗します。

ロールバックとエクスポートはストア内のデータのみを読み取るため、特別なサーバー連携は不要です。ただし、ロールバックは稼働中のリージョンファイルを直接上書きするため、必ずサーバーを停止してから行ってください。
