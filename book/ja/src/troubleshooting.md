# トラブルシューティング

- `unknown snapshot: N`: 指定されたスナップショット ID が存在しません。`list` コマンドで有効な ID を確認してください。なお、一度使用された ID が再利用されることはありません。
- `blob missing from CAS: <hex>`: ストア内のデータ破損、あるいは不完全にコピーされたストアであることを示します。不完全なワールドを書き戻すことによる破損リスクを避けるため、ロールバックは即座に中断されます。`--on-missing-blob skip-chunk`（`rollback` / `export` で利用可能）を指定すると、影響を受けるチャンクを除外して処理を続行できます。二次バックアップからストアを復元した上で、破損の原因を調査してください。
- `cannot derive region path for dim ...` (`UnknownRegionPath`): 配置先フォルダが不明なカスタムディメンションのリージョンであるか、`--on-missing-file error` が指定されていてフォルダ位置の推測が無効化されていることを示します。兄弟フォルダからの自動導出が機能するようにバックアップ元と同一のフォルダ構成を持つワールドに対して実行するか、そのリージョンが復元対象外であることを許容してください。
- `unsupported schema version`: ストアがより新しい（またはより古い）バージョンのバイナリによって書き込まれています。本プロジェクトは現在プレリリース段階のため、自動マイグレーションはサポートされていません。ストアを再作成してください。
- リージョンファイルの解析失敗（`failed to process region file ...`）: エラーメッセージに対象ファイル名が表示されます。サーバーのセーブ中断などによって生じたファイルの末尾データ破損（torn tail）は、ヘッダーから参照されていない限り許容されますが、実際に参照されている破損セクタ（corrupt sector run）は設計上エラーとして明確に検知・報告されます。
- 処理が極端に遅い場合: リリースビルド（`--release`）を使用していることを確認した上で、`--timing` オプションを付けて再実行し、どのフェーズで時間がかかっているか比較してください。バックアップ処理が遅い場合は、リージョンごとの詳細な処理時間内訳が含まれる `--timing --json` の併用を推奨します。
