# エクスポート

```sh
sekai --store ./sekai-store export 1 ./restored
```

指定したスナップショットを新しいディレクトリに再構築（出力）します。
ロールバックとは異なり、稼働中のワールドに一切影響を与えません。エクスポートはロールバックと同じ復元ロジックを使用しますが、すべてのファイルを指定した出力先ディレクトリ配下に、レイアウトに従ったパスで書き出します。スナップショットの引数には `<id>` または `@tag` を指定できます（詳細は[タグ](tags.md)を参照）。

- 出力先ディレクトリは存在しない場合に自動作成されます。既存のディレクトリを指定する場合は、空のディレクトリである必要があります。既存データの上書き・破壊を防ぐため、中身が存在する場合はエラーを返して安全に中断します。
- `--flavor legacy|new|bukkit`: 出力レイアウトの形式を指定します（`legacy`: `region/`, `DIM-1/`, `DIM1/`、`new`: `dimensions/minecraft/<name>/`、`bukkit`: ディメンションごとにフォルダを分割）。`--base` は bukkit フレーバー時のオーバーワールドのフォルダ名を指定します（`level-name`、デフォルトは `world`）。
- スコープフラグ（`--in`, `--region`, `--kind`）: エクスポートする対象範囲を制限します。全チャンクがツームストーン（削除済み）のリージョンはファイル自体が出力されません。詳細は[スコープ（対象範囲）の選択](../scope.md)を参照してください。
- `--on-missing-blob skip-chunk`: Blob が欠損しているチャンクをスキップして処理を継続します（デフォルトはロールバックと同様に `abort`）。
- パスを自動導出できるのはバニラのネームスペース（ディメンション）のみです。カスタムディメンションの場合は誤った場所に出力されるのを防ぐため、エラー（`UnknownRegionPath`）を返して安全に中断します。
