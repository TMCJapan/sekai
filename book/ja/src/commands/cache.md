# キャッシュ

```sh
sekai cache clean
```

`cache` はリージョンイメージキャッシュを管理するコマンドです。キャッシュはストア内の高速化専用キースペース（`meta.sqlite` や `blobs/` と並ぶ `cache/`）で、コミット済みリージョンノードハッシュごとに、その元となった未展開の `.mca` イメージを保持します。これにより、後続のコミットはチャンクを1つも解凍・正規化することなく、完全にカバーされたリージョンが不変であることを証明できます（[基本概念](../concepts.md)を参照）。

キャッシュは派生データであり、履歴そのものではありません。すべてのエントリはワールドとスナップショットツリーから再計算できます。

- `cache clean` はキャッシュされたすべてのエントリを削除し、削除件数を表示します:

  ```text
  cleared 12 cached region image(s)
  ```

  いつ実行しても安全です。削除してもコミットやチェックアウトが読み書きする内容は一切変わらず、次のコミットが必要なエントリを再構築するまでの間、パフォーマンスが低下するだけです。空のキャッシュに対して再実行すると `0` が表示されます（冪等な操作です）。
- 容量削減のために使用します。コミットと Blob は追記専用で削除されることはないため、ストア内で縮小できるのはキャッシュだけです。[二次バックアップ](../store.md)の前に削除しておくとコピーを小さく保てます。復元したストアは、次のコミットまでキャッシュが冷えた状態で動作するだけです。
- ストアは事前に作成しておく必要があります。先に `sekai init` を実行してください（[ストアの場所](../store.md)を参照）。ストアが存在しない場合、何も作成せずに失敗します。
- `--json` を指定すると削除件数が `entries` として出力されます。ペイロードの完全な仕様は [docs/json.md](https://github.com/tmcjapan/sekai/blob/main/docs/json.md) を参照してください。計測するフェーズやカウントする項目がないため、`--timing` と `--progress` は利用できません。
