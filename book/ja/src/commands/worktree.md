# ワークツリー

```sh
sekai worktree add ../feature            # 新しいブランチ "feature"
sekai worktree add ../hotfix v1          # v1 で detach
sekai worktree list
sekai worktree remove feature
```

ワークツリーは、Git のワークツリーがリポジトリを共有するのと同じように、ストアを共有する別のワールドです。それぞれが自分の HEAD を持つため、2つのワールドを別々のブランチに置けます。

- `worktree add <path> [<commit-ish>]` は、このワールドを `<path>`（存在しないか空である必要があります）にコピーし、リージョンファイルをコミットから再構築します。commit-ish を省略するとディレクトリ名のブランチを作ります。ブランチを指定するとそれをチェックアウトし、それ以外は HEAD を detach します。別の場所でチェックアウトされているブランチは拒否されます。サーバーの場合は、ワールドを含むサーバーディレクトリを、ストアとロックファイルを除いてコピーします。
- `worktree list` は、各ワールドのルートをコミットとブランチとともに表示します。
- `worktree remove <worktree>` は、パスの末尾で一意に指定したリンクされたワークツリーの登録を解除し、リンクファイルを削除します。ワールドのファイルは残ります。ストアを持つワールドであるメインワークツリーは削除できません。
