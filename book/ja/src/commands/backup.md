# バックアップ

```sh
sekai --store ./sekai-store backup ./world
```

現在のワールド状態を新しいスナップショットとして記録します。完了時にはスナップショット ID、チャンク数および Blob 数、ツームストーン数、スキップされたリージョン数、引き継がれたチャンク数が表示されます。

- `--with-diff`: Blob に加えて差分計算用の一時的な Diff ビューを導出します（インジェスト時間は長くなります。このオプションを指定しない場合、最も高頻度で実行されるインジェスト処理（ホットパス）において NBT デコードが一切発生せず、高速に処理されます）。
- `--jobs N`: インジェストのワーカースレッド数を設定します（`0` を指定すると CPU コア数と同等のスレッド数が割り当てられます）。
- `--progress`: 標準エラー出力に進捗バーを表示します（`--json` との併用は不可）。
- スコープフラグ（`--in`, `--region`, `--kind`）: 記録対象の範囲を制限します。詳細は[スコープ（対象範囲）の選択](../scope.md)を参照してください。
- バックアップ内容の事前確認（dry-run プレビュー）を行いたい場合は、[検証・検査](inspection.md)の `status` コマンドを使用してください。
- バックアップ実行時にストアディレクトリが新規作成された場合は、通常テキスト出力時（human 出力）に標準エラー出力へその旨が表示されます。

更新のないリージョンファイルはフィンガープリントによってスキャン自体がスキップされます。また、更新されたリージョン内にある変更のないチャンクは過去のスナップショットへのフォールバックによって解決されるため、新たな Blob は書き込まれません。ワールドに変更が全くない場合でも、新しいスナップショット行が1件記録されます。
